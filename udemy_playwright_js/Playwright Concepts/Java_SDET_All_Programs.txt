4.) SWAP TWO NUMBERS WITHOUT THIRD VARIABLE
================================================================

CODE:
  int a = 5, b = 10;
  a = a + b;    // a = 15
  b = a - b;    // b = 15 - 10 = 5
  a = a - b;    // a = 15 - 5 = 10

HOW IT WORKS:
  Step 1: a = a + b → a = 5 + 10 = 15 (a now holds SUM of both)
  Step 2: b = a - b → b = 15 - 10 = 5 (subtract old b from sum → original a)
  Step 3: a = a - b → a = 15 - 5 = 10 (subtract new b from sum → original b)

  The SUM acts as temporary storage. By subtracting one value from
  the sum, you recover the other value.

INTERVIEW TIP: "The arithmetic trick works but can overflow for large
numbers. XOR swap (a ^= b; b ^= a; a ^= b;) avoids overflow."

5.) FACTORIAL OF A NUMBER
================================================================

CODE:
  int factorial = 1;
  int number = 5;
  for (int i = 1; i <= number; i++) {
      factorial = factorial * i;
  }
  // Output: 120

HOW IT WORKS:
  Factorial = product of all numbers from 1 to n.
  5! = 5 × 4 × 3 × 2 × 1 = 120

  DRY RUN (number = 5):
    i=1: factorial = 1 * 1 = 1
    i=2: factorial = 1 * 2 = 2
    i=3: factorial = 2 * 3 = 6
    i=4: factorial = 6 * 4 = 24
    i=5: factorial = 24 * 5 = 120

  WHY start factorial at 1? Because multiplying by 0 gives 0.
  WHY loop from 1 to n? We multiply every integer in that range.

6.) REVERSE A NUMBER
================================================================

CODE:
  int no = 15786, rev = 0, r;
  while (no > 0) {
      r = no % 10;        // Extract last digit
      rev = rev * 10 + r; // Append digit to reversed number
      no = no / 10;       // Remove last digit from original
  }
  // Output: 68751

HOW IT WORKS:
  The MODULO trick: num % 10 always gives the LAST digit.
  The DIVISION trick: num / 10 always REMOVES the last digit.
  Build the reversed number by multiplying by 10 (shift left) and adding new digit.

  DRY RUN (no = 15786):
    r = 15786 % 10 = 6,  rev = 0*10 + 6 = 6,    no = 15786/10 = 1578
    r = 1578 % 10 = 8,   rev = 6*10 + 8 = 68,   no = 1578/10 = 157
    r = 157 % 10 = 7,    rev = 68*10 + 7 = 687,  no = 157/10 = 15
    r = 15 % 10 = 5,     rev = 687*10 + 5 = 6875, no = 15/10 = 1
    r = 1 % 10 = 1,      rev = 6875*10 + 1 = 68751, no = 1/10 = 0
    Loop ends (no = 0). Result: 68751 ✓

KEY PATTERN: % 10 extracts last digit. / 10 removes last digit.
This pattern is used in: reverse number, palindrome, Armstrong, digit count, sum of digits.

7.) ARMSTRONG NUMBER
================================================================

CODE:
  int no = 153, arm = 0, d = no;
  while (no > 0) {
      int a = no % 10;     // Extract last digit
      no = no / 10;        // Remove last digit
      arm = arm + a*a*a;   // Add cube of digit
  }
  if (arm == d) → "Armstrong number"

HOW IT WORKS:
  Armstrong number: sum of cubes of digits = the number itself.
  153 → 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 ✓

  DRY RUN (no = 153):
    a = 153%10 = 3, arm = 0 + 3*3*3 = 27,  no = 153/10 = 15
    a = 15%10 = 5,  arm = 27 + 5*5*5 = 152, no = 15/10 = 1
    a = 1%10 = 1,   arm = 152 + 1*1*1 = 153, no = 1/10 = 0
    arm(153) == d(153) → Armstrong! ✓

  Other Armstrong numbers: 0, 1, 153, 370, 371, 407

9.) PALINDROME NUMBER
================================================================

CODE:
  int originalNumber = num;
  int reversedNumber = 0;
  while (num != 0) {
      int digit = num % 10;
      reversedNumber = reversedNumber * 10 + digit;
      num = num / 10;
  }
  return originalNumber == reversedNumber;

HOW IT WORKS:
  A palindrome reads the same forwards and backwards (121, 1001, 12321).
  Strategy: Reverse the number, then compare with original.
  Uses the SAME reverse logic as Program 6.

  DRY RUN (num = 1001):
    Save original: originalNumber = 1001
    digit=1, rev=1, num=100
    digit=0, rev=10, num=10
    digit=0, rev=100, num=1
    digit=1, rev=1001, num=0
    1001 == 1001 → Palindrome! ✓

10.) SUM OF DIGITS
================================================================

CODE:
  int number = 12345, sum = 0;
  while (number > 0) {
      int digit = number % 10;
      sum = sum + digit;
      number = number / 10;
  }
  // Output: 15

HOW IT WORKS:
  Extract each digit (% 10), add to sum, remove digit (/ 10).
  12345 → 1+2+3+4+5 = 15

  DRY RUN:
    digit=5, sum=5, number=1234
    digit=4, sum=9, number=123
    digit=3, sum=12, number=12
    digit=2, sum=14, number=1
    digit=1, sum=15, number=0 → Answer: 15

S1.) REVERSE A STRING
================================================================

CODE:
  String input = "hello";
  String nstr = "";
  for (int i = 0; i < input.length(); i++) {
      char ch = input.charAt(i);
      nstr = ch + nstr;   // Prepend character
  }
  // Output: "olleh"

HOW IT WORKS:
  Instead of appending to the end, PREPEND each character to the front.
  
  DRY RUN ("hello"):
    i=0: ch='h', nstr = 'h' + "" = "h"
    i=1: ch='e', nstr = 'e' + "h" = "eh"
    i=2: ch='l', nstr = 'l' + "eh" = "leh"
    i=3: ch='l', nstr = 'l' + "leh" = "lleh"
    i=4: ch='o', nstr = 'o' + "lleh" = "olleh" ✓

KEY INSIGHT: nstr = ch + nstr (prepend) reverses the order.
If we did nstr = nstr + ch (append), we'd get the same string back.

S6.) ALL PERMUTATIONS OF A STRING
================================================================

CODE:
  static void permute(String str, String prefix) {
      if (str.length() == 0) {
          System.out.println(prefix);
      } else {
          for (int i = 0; i < str.length(); i++) {
              String rem = str.substring(0,i) + str.substring(i+1);
              permute(rem, prefix + str.charAt(i));
          }
      }
  }

HOW IT WORKS (RECURSION):
  "abc" → pick each character as first, permute the rest.
  Pick 'a': permute "bc" → "abc", "acb"
  Pick 'b': permute "ac" → "bac", "bca"
  Pick 'c': permute "ab" → "cab", "cba"
  
  Base case: when string is empty, print the prefix (complete permutation).
  n! permutations total: 3! = 6 for "abc".

S7.) STRING PALINDROME
================================================================

CODE:
  int start = 0, end = str.length() - 1;
  while (start < end) {
      if (str.charAt(start) != str.charAt(end)) return false;
      start++;
      end--;
  }
  return true;

HOW IT WORKS:
  Two pointers: one at start, one at end.
  Compare characters. If different → not palindrome. Move inward.
  If all pairs match → palindrome.
  "madam": m==m ✓, a==a ✓, d==d (middle) ✓ → palindrome!

S20.) LONGEST SUBSTRING WITHOUT REPEATING CHARACTERS
================================================================

CODE:
  HashSet<Character> set = new HashSet<>();
  int maxLength = 0, start = 0, end = 0;
  while (end < s.length()) {
      char currentChar = s.charAt(end);
      if (!set.contains(currentChar)) {
          set.add(currentChar);
          maxLength = Math.max(maxLength, end - start + 1);
          end++;
      } else {
          set.remove(s.charAt(start));
          start++;
      }
  }

HOW IT WORKS (SLIDING WINDOW):
  Maintain a window [start, end] with no repeating characters.
  - If current char is new: add to set, expand window (end++).
  - If current char is duplicate: shrink window from left (start++), remove that char.
  - Track maximum window size.
  
  "abcabcbb":
    Window: a → ab → abc (max=3) → bc → bca... → max stays 3
  
  This is O(n) — each character is added/removed from set at most once.

A3.) SORT ARRAY WITHOUT BUILT-IN METHOD (Selection Sort)
================================================================

CODE:
  for (int i = 0; i < n - 1; i++) {
      int minIndex = i;
      for (int j = i + 1; j < n; j++) {
          if (array[j] < array[minIndex]) minIndex = j;
      }
      // Swap array[i] and array[minIndex]
      int temp = array[i];
      array[i] = array[minIndex];
      array[minIndex] = temp;
  }

HOW IT WORKS:
  For each position: find the MINIMUM element in the remaining unsorted part.
  Swap it into the current position.
  [5, 2, 9, 1, 6]:
    i=0: min=1 at index 3, swap → [1, 2, 9, 5, 6]
    i=1: min=2 at index 1, no swap → [1, 2, 9, 5, 6]
    i=2: min=5 at index 3, swap → [1, 2, 5, 9, 6]
    i=3: min=6 at index 4, swap → [1, 2, 5, 6, 9] ✓

A6.) FIND MISSING NUMBER IN ARRAY
================================================================

CODE:
  int n = array.length + 1;
  int totalSum = n * (n + 1) / 2;
  int arraySum = 0;
  for (int num : array) arraySum += num;
  return totalSum - arraySum;

HOW IT WORKS:
  Formula: sum of 1 to n = n*(n+1)/2
  If one number is missing: expected sum - actual sum = missing number.
  
  array = [1, 2, 4, 5, 6], n = 6
  Expected sum = 6*7/2 = 21
  Actual sum = 1+2+4+5+6 = 18
  Missing = 21 - 18 = 3 ✓

INTERVIEW TIP: "This is O(n) time, O(1) space. The math formula
avoids sorting or extra data structures."

HASHCODE AND EQUALS (BONUS)
================================================================

WHY IT'S ASKED:
  - equals() determines if two objects are "logically equal."
  - hashCode() returns a number used by HashMap/HashSet for storage.
  - RULE: If two objects are equal (equals=true), they MUST have same hashCode.
  - Used in: HashSet, HashMap, comparing test data objects.

CODE:
  @Override
  public boolean equals(Object obj) {
      if (this == obj) return true;        // Same reference
      if (obj == null || getClass() != obj.getClass()) return false;
      Student student = (Student) obj;
      return id == student.id && Objects.equals(name, student.name);
  }

  @Override
  public int hashCode() {
      return Objects.hash(id, name);
  }

INTERVIEW TIP: "If you override equals, you MUST override hashCode.
Otherwise HashMap/HashSet won't work correctly — two 'equal' objects
could end up in different buckets."
