Memory Tricks

CSS Symbols:
# = ID (hashtag = identity)
. = Class (dot notation)
[] = Attribute (brackets)
*= = Contains (wildcard)
^= = Starts with (caret = beginning)
$= = Ends with (dollar = end)
XPath Symbols:
// = Relative (start anywhere)
/ = Direct child (one level)
@ = Attribute prefix
:: = Axis separator (parent::, sibling::)
* = Any tag
[] = Filter/condition

Method Where How Unique Result
